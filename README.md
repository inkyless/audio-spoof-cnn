## EN Version

### About 
This project is part of personal thesis researching about "Audio Spoof Detection With CNN Model". The main purpose of this research is to make comparison between CNN based models with variations tested. The audio compression to 8000hZ sample rate will be used as augmentation technique for this research. 

### Tools Used
FrontEnd : React JS (Vite)
BackEnd : FastAPI
Database : MySQL 
Deployment : Docker
